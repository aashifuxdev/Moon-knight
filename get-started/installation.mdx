Choose your preferred package manager.

<CodeGroup>

```bash npm
npm install moon-knight
```

```bash yarn
yarn add moon-knight
```

```bash pnpm
pnpm add moon-knight
```

</CodeGroup>

## Requirements

| Requirement | Minimum version |
| ----------- | --------------- |
| Node.js     | 18.0            |
| npm         | 9.0             |

<Warning>
  Node.js versions below 18 are not supported.
</Warning>
