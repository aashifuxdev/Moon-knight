title: "Quickstart"
description: "Set up Moon Knight in a few minutes"
icon: "rocket"
---

Follow these steps to get started.

<Steps>
  <Step title="Install the CLI">
    ```bash
    npm install -g moon-knight
    ```
  </Step>
  <Step title="Initialize a project">
    ```bash
    moon-knight init my-project
    ```
  </Step>
  <Step title="Run locally">
    ```bash
    cd my-project && moon-knight dev
    ```
  </Step>
</Steps>

<Tip>
  Run `moon-knight --help` to see every available command.
</Tip>
